### Юпитер — учёт продукции и сертификаты качества

**Завершённый коммерческий проект для производственного предприятия**

Разработал настольное приложение для учёта бухт порошковой проволоки, оформления сертификатов качества и печати ярлыков.

**Моя работа:**

- Разобрал существующее приложение на Visual FoxPro и структуру его данных.
- Разработал приложение на C#/.NET с локальной базой SQLite и переносом архивных данных.
- Реализовал работу с бухтами, сертификатами, справочниками, фильтрами и статусами.
- Добавил формирование PDF, индивидуальных и общих комплектов ярлыков с QR-кодами.
- Реализовал обновление данных сертификата при изменении связанной бухты и сохранение предыдущих редакций.
- Дорабатывал интерфейс и печатные формы по обратной связи заказчика, подготовил установщик.

**Результат:** проект завершён и оплачен заказчиком. Разработка велась с учётом целевой среды Windows 7 x86

**Стек:** C#, .NET Framework, Windows Forms, SQLite, PDF, QR.
